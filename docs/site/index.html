i18n for Joe Gaudet's libraries

One translator for every library's strings.

The shared translator contract for ember-joinery, ember-formwright and real-enums. Translate their built-in strings with the i18n system your app already uses: gettext first-class, i18next, FormatJS (and so ember-intl) and Lingui through adapters.

API reference GitHub
$ npm i msgid

Then install the i18n library its adapter wraps, if any.

Usage

Pick an adapter, get a translator.

A Translator is a locale and a t(message, values) function. Every adapter falls back to English for a message its catalog lacks, so you can translate one string at a time. 

import { format, pseudo } from 'msgid'

format({ id: 'x.files', message: '{count} file', plural: '{count} files' }, { count: 2 })
// '2 files'

pseudo().t({ id: 'x.hi', message: 'Hi {name}' }, { name: 'Ada' })
// '⟦Ĥí Ada⟧' (locale 'en-XA'), to spot strings that skipped the translator in tests
import { gettext } from 'msgid/gettext'
import pl from './translations/pl.json' // from `msgid po2json pl.po`

const translator = gettext(pl) // locale from the .po file's Language header

The API reference covers every adapter and catalog builder; the README has the Ember, i18next, FormatJS and Lingui setup and the catalog CLI.
